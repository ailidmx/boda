# Sistema de Preguntas Puzzle / Systeme de questions puzzle

## ES
Objetivo:
Resolver el proyecto por micro-decisiones guiadas hasta llegar a una vista final totalmente detallada.

Regla de operacion:
1. Se elige una pregunta prioritaria.
2. Se responde con decision clara o con dato pendiente.
3. Se actualiza tarea relacionada.
4. Se recalcula impacto en presupuesto, logistica o experiencia.
5. Se pasa a la siguiente pregunta.

Cadencia sugerida:
- 5 preguntas por sesion corta.
- 1 cierre semanal de decisiones congeladas.

Criterio de calidad:
- Cada respuesta debe cerrar una ambiguedad real.
- Si no hay dato suficiente, se crea accion de obtencion de dato.

## FR
Objectif :
Resoudre le projet par micro-decisions guidees jusqu'a une vision finale totalement detaillee.

Regle d'operation :
1. On choisit une question prioritaire.
2. On repond avec une decision claire ou un manque d'information.
3. On met a jour la tache liee.
4. On recalcule l'impact budget, logistique ou experience.
5. On passe a la question suivante.

Cadence suggeree :
- 5 questions par session courte.
- 1 cloture hebdomadaire des decisions gelees.

Critere qualite :
- Chaque reponse doit fermer une ambiguite reelle.
- Si la donnee manque, on cree une action pour la recuperer.
