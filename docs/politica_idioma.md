# Politica de idioma / Politique linguistique

## ES
Todo el contenido generado para este proyecto debe producirse en dos versiones:
- Espanol
- Frances

Reglas de aplicacion:
- Documentos de planeacion: siempre bilingues (ES + FR).
- Plantillas de comunicacion a invitados: siempre bilingues (ES + FR).
- Contenido web publico: siempre bilingue (ES + FR).
- Si se requiere version corta, mantener ambas lenguas en el mismo entregable.

## FR
Tout le contenu genere pour ce projet doit etre produit en deux versions :
- Espagnol
- Francais

Regles d'application :
- Documents de planification : toujours bilingues (ES + FR).
- Modeles de communication aux invites : toujours bilingues (ES + FR).
- Contenu web public : toujours bilingue (ES + FR).
- Si une version courte est necessaire, conserver les deux langues dans le meme livrable.
