# Boda David AILI + Ayde Juarez

Fecha objetivo: fin de semana del 20 de febrero de 2027.

## Datos ya confirmados
- Venue: Roca Azul, Jocotepec, Jalisco, Mexico
- Alojamiento asegurado en cabanas del venue
- Estancia cubierta: viernes a domingo (2 noches)
- Desayunos incluidos para ~80 personas

Este repo es la base documental y operativa de la boda:
- Planeacion y timeline
- Presupuesto
- Invitados y comunicacion
- Proveedores y contratos
- Operacion del evento
- Publicacion web

## Estructura
- `docs/`: estrategia, decisiones y planes maestros
- `tasks/`: backlog y seguimiento de tareas
- `invitados/`: base de datos de invitados y mesas
- `viajes/`: vuelos, estancias y traslados de invitados que vienen de lejos
- `comunicacion/`: mensajes y plantillas para invitados
- `proveedores/`: evaluacion, contratos y checklists
- `vestuario/`: concepto y decisiones de vestuario de los novios
- `operacion_evento/`: runbook del dia de boda
- `web/`: contenido y activos de la web publica

## Regla operativa
Cada cambio importante debe actualizar:
1. Un documento en `docs/`
2. Una tarea en `tasks/backlog.md`
3. Si aplica, una plantilla de `comunicacion/templates/`

Modo de ejecucion:
- Auto-integrado por defecto (sin confirmaciones intermedias para cambios normales).
- Referencia: `docs/protocolo_ejecucion_autonoma.md`
