# Fichas de cabañas

Este directorio es la base de conocimiento detallada de las unidades de
alojamiento. Cada cabaña tiene un archivo JSON estable que puede reutilizarse
en la invitación, la asignación de huéspedes y la operación del fin de semana.

La capacidad anunciada por el lugar y los couchages deducidos de las camas se
guardan por separado. No se inventan camas adicionales para hacer coincidir
ambas cifras: cualquier diferencia queda marcada para confirmación.
