# Approved public images

Only metadata-free, web-optimized derivatives explicitly approved for public use belong here. Import an approved file from `src/media.js` to include it in the production build.

`couple-002.webp` through `couple-018.webp` are the cleaned derivatives of
the source set approved on 2026-07-28.

`couple-new-*.webp` are the derivatives of the second batch approved on
2026-07-29 (17 photos from `para invitacion 2`), sorted chronologically
by capture date (2016 → 2024).

The current hero and gallery selection is controlled exclusively from
`src/media.js`.
